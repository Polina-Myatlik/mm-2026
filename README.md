# Дашборд заказов клиента

## Запуск
1. Распакуйте архив целиком.
2. Откройте терминал/командную строку именно в этой папке (рядом с `index.html` и `data.csv`).
3. Выполните `python -m http.server 8000` (или `python3 -m http.server 8000`).
4. Откройте http://localhost:8000

Нужен доступ к CDN для Vue 3, D3.js и PapaParse.

## Фильтр категории и месячные графики
Выбор категории обновляет оба месячных графика. Траты — сумма по товарам выбранной категории, заказы — число уникальных заказов с товарами этой категории. «Все категории» возвращает общую динамику. Фильтры статуса и года продолжают действовать.

В графике «Динамика трат по месяцам» фиолетовая линия показывает траты (левая ось, ₽), оранжевая пунктирная — уникальные заказы (правая ось, шт.). При наведении выделяются обе точки месяца и показываются оба значения.

## Критерии оценивания
Текущие значения за последний месяц данных; по умолчанию динамика за сентябрь 2024 — август 2026 (24 месяца). Добавлены динамика скидки, полосы количества и расходов в товарном рейтинге, подсказки с динамикой фактической цены за единицу (расходы / количество по месяцам). Изображения увеличиваются при наличии файла. Категория фильтрует метрики и все графики. Месяцы без покупок имеют нулевые траты и заказы; скидка не определена. Полнота эксперимента оценивается по всей работе.
